# BLE 감시 (BleWatch)

주변 기기가 내보내는 블루투스(BLE) 신호를 목록과 게이지로 보여 주는 도구입니다.
스마트 안경이나 무선 이어폰처럼 시험장에 있으면 안 되는 기기가 근처에 있는지 살펴보는 데 씁니다.

## 받기

**폰에서 바로 받기: https://yujoonchoi1001-create.github.io/blewatch/**

| 기기 | 파일 | 실행 |
|---|---|---|
| Android 폰 (8.0 이상) | [BleWatch-0.6.apk](docs/BleWatch-0.6.apk) | 위 주소를 폰에서 열어 받고 설치 |
| Windows PC (10, 11) | [BleWatch-PC.zip](docs/BleWatch-PC.zip) | 압축을 풀고 더블클릭 |

iPhone은 지원하지 않습니다.

## 설치할 때 나오는 경고

스토어를 거치지 않은 앱이라 경고가 나옵니다.

- **갤럭시**: 설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단을 끄고 설치한 뒤 다시 켭니다.
- **"출처를 알 수 없는 앱"**: 팝업의 설정에서 "이 출처 허용"을 켭니다.
- **Play 프로텍트**: "세부정보 더보기 → 무시하고 설치"를 누릅니다.
- **Windows "PC 보호" 창**: "추가 정보 → 실행"을 누릅니다.

## 믿어도 되는 이유

- 소스 코드가 이 저장소에 전부 공개되어 있습니다.
- 폰 앱은 **인터넷 권한이 없습니다.** 잡은 신호를 어디로도 보낼 수 없습니다.
- 요청하는 권한은 블루투스 스캔과 진동뿐입니다. Android 12 이상에서는 위치 권한을 요청하지 않습니다. (Android 11 이하는 시스템이 블루투스 스캔에 위치 권한을 요구합니다.)
- 다른 기기에 접속하지 않고, 통신 내용을 읽지 않습니다. 공개적으로 방송되는 신호만 받습니다.

## 쓰는 법

1. 앱을 열고 "근처 기기" 권한을 허용하면 바로 스캔이 시작됩니다. 블루투스가 켜져 있어야 합니다.
2. 줄마다 게이지가 나옵니다. 가까울수록 길어지고 초록 → 주황 → 빨강으로 바뀝니다.
3. 줄을 누르면 그 신호만 큰 게이지로 추적합니다. 진동(PC는 소리)을 켜면 가까울수록 빨리 울립니다.
4. "기준선 저장"을 누르면 그 뒤에 새로 나타난 신호만 보여 줍니다.
5. "의심 기기만"은 가전·TV·PC와 멀리 있는 미분류 신호를 숨깁니다. 기본으로 켜져 있습니다.
6. "앱 공유"를 누르면 카카오톡 등으로 설치 파일을 바로 보낼 수 있습니다.

## 한계 (꼭 읽어 주세요)

- **잡히는 것**: BLE 광고 신호를 내는 기기. 일부 스마트 안경, 무선 이어폰, 워치, 폰.
- **광고를 끄는 기기는 못 잡습니다.** 폰과 연결된 뒤 BLE 광고를 멈추는 기기가 있고, 스마트 안경 중에도 이런 모델이 있을 수 있습니다. 그 경우 이 앱에는 아무 신호도 뜨지 않습니다. 어떤 모델이 그런지는 실물로 확인하지 못했습니다.
- **그 밖에 못 잡는 것**: 유도 루프형 초소형 이어폰, 녹화만 하는 카메라, 꺼진 기기.
- 기기 종류는 제조사 ID와 이름으로 한 **추정**입니다. "안경 의심"에는 같은 제조사의 다른 기기가 섞일 수 있습니다.
- 빨간 게이지는 "가깝다"는 뜻이지 "수상하다"는 뜻이 아닙니다.
- 신호 세기는 사람 몸과 벽에 따라 크게 흔들립니다.
- **신호가 잡힌 것은 확인이 필요하다는 단서이지 부정행위의 증거가 아닙니다.** 신호가 없다고 기기가 없는 것도 아닙니다.
- 실제 스마트 안경으로 검증하지 못한 시험판입니다.

## 시험장에서

- 수험생은 전자기기를 시험장에 반입할 수 없으므로 이 앱을 쓸 수 없습니다.
- 감독관은 시험장 본부의 허가를 받고, 규정이 허용하는 범위에서만 쓰세요.
- 의심되는 경우 직접 판단하지 말고 정해진 절차(금속탐지기 검사, 본부 보고)를 따르세요.

## 직접 빌드

- 폰 앱: JDK 17과 Android SDK 34가 있는 환경에서 `gradle assembleDebug`
- PC용: `pc/BleWatchPC.cs`를 .NET Framework의 `csc.exe`로 컴파일 (WinRT 메타데이터 참조 필요)
